## Why the code you copied stopped working

Three things kill Macy's coupon codes, and none of them is "the site is broken."

**They expire in days, not months.** Macy's promo codes are usually tied to a single event — a two-day home sale, a seasonal event, a brand launch. Aggregator pages keep them up for months after. The bedding code `HOME`, for example, has been recycled across home events including a two-day home sale in mid-August, but the specific discounts attached to it changed with each event.

**One code per transaction.** Macy's own terms for its app-only offers state that only one code can be used per transaction. There is no stacking two text-entry codes on the same order.

**Most codes are label-gated.** This is the big one. A code that says "extra 30% off" usually applies only to items carrying a specific label in that promotion. Add a brand that's excluded — and the exclusion list runs into the hundreds of brands, from Nike and Dyson to Le Creuset and UGG — and the code quietly does nothing for your cart.

## The fine print that decides whether a code works

Macy's publishes exclusion lists that are genuinely long. The terms attached to the `APPFINDS` offer, for instance, exclude whole departments — furniture, mattresses, baby gear, golf clothing, kids' shoes, restaurant and salon services, third-party seller items — plus dozens of brands by name. The same offer doesn't apply to Last Act Clearance, Backstage, or Macy's Wine Shop purchases.

That's normal for Macy's, not an outlier. Practical takeaway: before you commit to a purchase because of a code, add the item to your bag and check the savings line. Macy's shows you the discount that actually applied before you pay. If the number doesn't move, the item is excluded, and you've just saved yourself a return.

So the two savings layer have to be chosen deliberately, not blindly stacked.

The category exclusions are just as important. Cashback isn't earned on:
